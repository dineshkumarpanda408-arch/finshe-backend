Download FinShe

Use a direct file URL (ends in .apk) so the phone or PC starts the download immediately. If you host with Firebase (see repo firebase.json), the server sends Content-Disposition: attachment for .apk files.

Direct download links (examples)

Firebase Hosting (recommended): deploy this folder — share

Google Drive: share file → copy ID from …/file/d/FILE_ID/view → use:
https://drive.google.com/uc?export=download&id=FILE_ID

GitHub Releases: upload APK as a release asset → use the asset’s …/releases/download/…/file.apk URL (usually downloads directly).

Dropbox: change www.dropbox.com to dl.dropboxusercontent.com or add dl=1 for raw file access.
